Intro JS

Estructuras

  • Secuencial: De arriba hacia abajo, como terminna una instrucción
  • Condicionales: if/else - switch - try/catch try/except if/elif/else
  • Ciclos: for - while - do while - repeat until
  • Funciones: 1.- como las defino?, 2.- como las invoco?

Comentarios

  • de bloque: /* */
  • en la misma linea: //
  • de una línea //

Tipos de Datos

  • Simples, primitivas
  • Numéricos: integer, float, binarios, octales, hexadecimal, doble...
  • Date: TimeDate, time
  • caracteres, string, cadenas, alphanumérico
  • boolean True, False
  • vacíos: None, Undefined, null
  • Complejos, colecciones
  • Array, objetos, funciones

Operadores

  • asignación: =
  • aritméticos: + - * / // % **
  • lógicos: and, or, not - && || !
  • comparación: '== >= != > >'
  • ternario: decisión
  • de caracteres: concatenación: + repetición: *

Naming

  • camelCase : 1ra palabra minúscula, 2da palabra inicia en Mayúscula
  • PascalCase : 1ra palabra Mayúscula, 2da palabra inicia en Mayúscula
  • snake_case : todo en minúscula, separados por guión bajo
  • kebab-case : todo en minúscula, separado por guión medio
